# 杭州 → 南京 自驾行程地图（2026/10/16–10/19）

在线查看：https://frz0525.github.io/nanjing-trip-map/

两人自驾杭州 → 南京（住新街口·酒店待定 3 晚）的交互式行程地图：

- **自驾**：10/16 周五晚去程、10/19 周一争取 12:00 前返程，走 G25 杭宁高速，单程约 271 km。服务区与充电提示内置。
- **日程**：17 日上午纪念馆 → 下午总统府 → 晚上夫子庙/老门东；18 日中山陵（地铁+接驳）→ 南博下午场；19 日鸡鸣寺→台城→玄武湖后返程。
- **抢票时间表**：纪念馆 10/10 8:00 上午场；中山陵 10/11 16:00；南博 10/11 18:00；总统府 10/15 0:00 下午场。
- **露营停车**：核实过的宽敞/便宜/有厕所选项（G25 服务区免费过夜休息 + 江宁房车营地）。
- **贴士**：吃、停车、不建议钟山自驾、酒店充电、周一中午前返程。
