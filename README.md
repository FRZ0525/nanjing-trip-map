# 杭州 → 南京 自驾行程地图（2026/10/16–10/19）

在线查看：https://frz0525.github.io/nanjing-trip-map/

两人自驾杭州 → 南京（住新街口 3 晚）的交互式行程地图，手机和电脑都能用：

- **自驾**：去程 10/16 周五晚、返程 10/19 周一午饭后，走 G25 长深高速（杭宁高速），单程约 271 km、约 3 小时。图上标出途经服务区（青山、太湖（长兴）、宜兴太湖、溧阳天目湖、溧水东庐山），电车单程无需充电，到酒店后充电。
- **南京三天行程**：每天一种颜色，景点按顺序编号，点击查看地址、开放时间、预约方式和交通；市内路线按 地铁 / 步行 / 打车 / 景区接驳车 分别画线。
- **抢票时间表**：纪念馆、中山陵、南京博物院、总统府的放票时间和入口，带倒计时。
- **贴士**：吃、停车、住、电车续航、周末人流、证件。
- 每个点都有「高德导航 / 高德查看 / 百度地图」按钮。

数据来源：路线由 OSRM / FOSSGIS 路由（OpenStreetMap 数据）预先计算后内置在页面中；坐标来自 OpenStreetMap（Nominatim / Overpass）；开放时间和预约规则来自各景区官网和官方公告（2026 年），出行前请再次确认。底图：在线打开默认 OpenStreetMap，本地文件打开默认 Esri。页面为单个 HTML 文件，Leaflet 已内联。
